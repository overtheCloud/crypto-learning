数字货币钱包开发系列教程

一套自包含的完整课程体系：1 篇公共基础 + 5 条公链 × 3 篇（概念与钱包 / 合约语法 / DeFi 实战）共 16 篇。按顺序读完并做完每篇的练习，你将能够：说出五条链的核心概念、独立开发各链钱包与智能合约、熟悉主流 DeFi 协议并能通过合约与 SDK 和 DeFi 交互。

课程目标（学完能达到什么）：
  • 概念：UTXO / 账户 / 对象三种模型、各链共识与费用机制，能清楚解释大部分术语
  • 钱包：一个助记词派生 5 链地址，独立完成转账、签名、监听入账
  • 合约：Solidity（ETH/TRON）、Rust+Anchor（SOL）、Move（SUI）独立编写部署
  • DeFi：理解 AMM / 借贷 / 预言机原理，能用代码调 Uniswap、Jupiter、Cetus 等协议

零基础（小白）从这里开始

本课程面向零基础读者：不需要任何区块链背景、不需要买币（全部操作在免费测试网完成）、不需要高等数学（用到的密码学在篇 00 会从头讲）。唯一的硬门槛是「会一门编程语言的基础语法」，按下表补齐后即可直接开始篇 00。

起步步骤要做什么推荐免费资源参考用时
① 编程预备学会 JavaScript 基础：变量、函数、对象、数组、async/await、命令行运行 Node.js 脚本MDN JavaScript 教程 / freeCodeCamp / 廖雪峰 JavaScript 教程（三选一）2–4 周
② 装好工具Node.js LTS、Git、VS Code；注册一个 GitHub 账号各官网下载即可半天
③ 正式开学从篇 00 公共基础开始，严格按编号顺序推进；先通读再动手做练习本课程全部 16 篇见下方学习顺序表
给小白的三个定心丸：
  • 不用花一分钱：所有链都有测试网，测试币在「水龙头」（faucet）免费领取，教程里的助记词只在测试网使用
  • 看不懂就放慢：每篇末尾有自检清单，全部能答「是」再进入下一篇；答不出的条目就是需要重读的小节
  • 每天 1–2 小时即可：全程约 5–7 个月，ETH 篇最重，TRON 篇可复用 ETH 知识快速带过

学习顺序

严格按编号顺序推进（页内「上一篇 / 下一篇」按钮已串联全部 16 篇）。公共基础篇是根基；五条链中 ETH 篇最重（DeFi 主战场），TRON 篇可快速带过（复用 EVM 知识）。每篇末尾的自检清单全部能答「是」再进入下一篇。
